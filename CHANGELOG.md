# Changelog

## 2.0.1

- Неудачный вход пишется в syslog (facility `auth`, ident `beam-wp`), чтобы fail2ban мог банить по этим записям: при неверном пароле WordPress отвечает HTTP 200, и фильтр по кодам 401/403 в access-логе nginx такие попытки не видит.
- Сниппет fail2ban обновлён под `/var/log/auth.log`. Лимит 429 в nginx остаётся отдельным необязательным правилом.
- В сниппетах убран лишний пробел в начале блока. Запись можно отключить константой `BEAM_DISABLE_LOGIN_FAIL_LOG` или фильтром `beam_security_log_login_failures`. IP берётся из `REMOTE_ADDR`, подмена — фильтром `beam_security_client_ip`.

## 2.0.0

- Встроены поля на основе Advanced Custom Fields PRO 6.7.0.1 («Поля» / BE.AM Fields, каталог `vendor-acf/`). Это собственная наработка: из апстрима не обновляется. Функции, классы, хуки `acf/*`, ключи `field_*`/`group_*`, формат `acf-json` и опции в базе не переименовывались.
- Лицензия пакета сменена на GPL-2.0-or-later.
- Удалены модуль ACF Offline, проверка и хранение лицензии, страница «Updates», апдейтер и обращения к серверам исходного плагина. Опция `acf_pro_license` в базе не читается и не меняется.
- Если на сайте уже активен оригинальный ACF или ACF Pro, встроенная копия не загружается.

## 1.5.0

- Модуль «Безопасность»: скрытие адреса входа (случайный слаг вида `login-k7f3q9` на сайт, 404 для гостей на `wp-login.php` и `/wp-admin`), аварийное отключение через `BEAM_DISABLE_HIDE_LOGIN`.
- Скрытие входа: для гостевого 404 на `/wp-admin` отключается админ-бар, иначе шаблон темы падает с фатальной ошибкой.
- Скрытие логинов: архивы авторов и REST `/wp/v2/users` доступны по праву `list_users`, а не любому вошедшему пользователю; право задаётся фильтром `beam_security_users_capability`.
- SMTP: `Beam\Core\Modules\Smtp\Config` в пространстве имён плагина, совместимый псевдоним `BeamSmtpConfig`; `get()` без аргумента возвращает все настройки.
- Подсказка и ручная проверка лимита попыток входа: сниппеты nginx и fail2ban для текущего публичного адреса входа.
- XML-RPC: сниппет nginx закрывает и `/xmlrpc.php` в корне, и путь в каталоге WordPress; проверка TLS по умолчанию включена, для локальных доменов отключается.
- Favicon: в режиме значений по умолчанию снова выводятся `icon_192` и `icon_512`.
- Отключение комментариев не затрагивает отзывы WooCommerce; исключения задаются фильтром `beam_disable_comments_excluded_post_types`.
- Уведомления на вкладках настроек больше не дублируются (их уже выводит WordPress для страниц в разделе «Настройки»).
- Документация: репозиторий публичный, для Bedrock нужно убрать старый загрузчик `mu-plugins/beam-core.php`. В админке показывается предупреждение, если найдена вторая копия плагина.

## 1.4.0

- Тексты в админке приведены к коротким нейтральным формулировкам.
