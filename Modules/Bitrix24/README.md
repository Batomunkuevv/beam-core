# Битрикс24

Заявки с сайта уходят лидами в Битрикс24 через входящий вебхук. Модуль выключен по умолчанию: **Настройки → BE.AM Core → Модули → Битрикс24 → Сохранить**.

## Вебхук

В Битрикс24: **Разработчикам → Другое → Входящий вебхук**, права **CRM**. Адрес вида `https://портал.bitrix24.ru/rest/1/код/` вставляется на вкладке **Битрикс24**. Сохранённый адрес целиком не показывается, пустое поле при сохранении его не стирает, удалить можно галкой «Удалить сохранённый вебхук». Опция `beam_bitrix24_webhook` не грузится автоматически.

Если задан `BITRIX24_WEBHOOK` (константа, переменная окружения или строка в `.env` Bedrock), он важнее настройки, а поле в админке только для чтения.

Кнопка «Проверить подключение» вызывает `crm.lead.fields`: лиды не создаются.

Пока вебхука нет, модуль ничего не отправляет и ничего не ломает.

## Лид из темы

```php
if (function_exists('beam_bitrix24_lead')) {
    beam_bitrix24_lead()
        ->title('Квиз сайта: ' . $name)
        ->name($name)                    // «Иван Иванов» → NAME, LAST_NAME; ФИО с отчеством → ещё SECOND_NAME
        ->phone($phone)                  // +7 (999) 123-45-67, 8 999… → 79991234567
        ->email($email)
        ->comments(['Квиз с сайта', '1. Вопрос → ответ'])
        ->source('WEB', 'Квиз сайта')
        ->assigned(33411)
        ->opened()
        ->field('UF_CRM_1700000000', 'значение')
        ->utm()                          // utm_* из запроса, cookie или адреса страницы
        ->context('form', 'quiz')
        ->sendLater();                   // после ответа посетителю
}
```

`send()` отправляет сразу и возвращает `Result`: `ok`, `id()` (номер лида), `error`, `description`, `toArray()`. `sendLater()` ставит отправку на `shutdown` и сначала отдаёт ответ посетителю (`fastcgi_finish_request`), поэтому форма не ждёт Битрикс24. Исключения наружу не выходят.

Любой другой метод REST:

```php
$result = beam_bitrix24()->call('crm.lead.get', ['id' => 42]);
```

Функции `beam_bitrix24()` и `beam_bitrix24_lead()` есть только при включённом модуле. Таймаут запроса 10 секунд.

## Ошибки и журнал

Ошибка пишется в `error_log` с методом и кодом Битрикс24, код вебхука в логе заменён на `••••`. На вкладке модуля видны последние 20 запросов: время, метод, результат и номер лида, без данных из заявок.

## Фильтры и действия

- `beam_bitrix24_webhook` — адрес вебхука после настройки и окружения.
- `beam_bitrix24_timeout` — таймаут запроса в секундах, по умолчанию 10.
- `beam_bitrix24_lead_fields` — поля лида перед отправкой; второй аргумент — `context()`.
- `beam_bitrix24_sent` — после `crm.lead.add`: `Result`, отправленные данные, контекст.
- `beam_bitrix24_response` — после любого запроса: `Result`, метод, параметры.
- `beam_bitrix24_log_enabled` — `false`, чтобы не вести журнал.
